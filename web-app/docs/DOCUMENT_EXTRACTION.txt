# X-Ray Document Extraction System

## Overview

The X-Ray system uses OpenAI's Vision API (GPT-4o) to automatically extract structured data from real estate documents, enabling intelligent, context-aware layouts without requiring users to manually open PDFs.

## Features

- **Auto Type Detection**: Automatically identifies document type (lease, inspection, pre-approval, etc.)
- **Structured Extraction**: Extracts data into type-safe TypeScript interfaces
- **Context-Aware Layouts**: Different view modes based on document type:
  - **Executive Mode**: Line-item list (leases, paystubs, bank statements)
  - **Card Mode**: Visual grid (inspections, ID documents)
  - **Digest Mode**: Narrative summary (pre-approvals, insurance)
- **Confidence Scoring**: Provides extraction confidence (0-1 scale)
- **Batch Processing**: Extract multiple documents concurrently

## Usage

### Single Document Extraction

```typescript
'use client';

import { useDocumentExtraction } from '@/hooks/useDocumentExtraction';
import { LeaseData } from '@/types/documents';

function DocumentUpload() {
  const { extractDocument, isProcessing, progress, result, error } = useDocumentExtraction();

  const handleUpload = async (file: File) => {
    // 1. Upload file to storage (Supabase, S3, etc.)
    const fileUrl = await uploadToStorage(file);

    // 2. Extract document data
    try {
      const extraction = await extractDocument(fileUrl, file.name);

      if (extraction.documentType === 'lease') {
        const leaseData = extraction.extractedData as LeaseData;
        console.log('Rent:', leaseData.terms.rentAmount);
        console.log('Move-in:', leaseData.terms.moveInDate);
      }

      // 3. Save to database
      await saveExtractedDocument({
        fileUrl,
        fileName: file.name,
        type: extraction.documentType,
        extractedData: extraction.extractedData,
        viewMode: extraction.viewMode,
        confidence: extraction.confidence,
      });

    } catch (error) {
      console.error('Extraction failed:', error);
    }
  };

  return (
    <div>
      <input type="file" onChange={(e) => e.target.files && handleUpload(e.target.files[0])} />

      {isProcessing && (
        <div>
          <p>Processing... {progress}%</p>
          <div className="progress-bar" style={{ width: `${progress}%` }} />
        </div>
      )}

      {error && <div className="error">{error}</div>}

      {result && (
        <div>
          <p>Type: {result.documentType}</p>
          <p>Confidence: {(result.confidence * 100).toFixed(0)}%</p>
          <p>View Mode: {result.viewMode}</p>
        </div>
      )}
    </div>
  );
}
```

### Batch Document Extraction

```typescript
import { useBatchDocumentExtraction } from '@/hooks/useDocumentExtraction';

function BulkUpload() {
  const { documents, extractDocuments } = useBatchDocumentExtraction();

  const handleBulkUpload = async (files: FileList) => {
    // Upload all files first
    const uploads = await Promise.all(
      Array.from(files).map(async (file) => ({
        id: generateId(),
        fileUrl: await uploadToStorage(file),
        fileName: file.name,
      }))
    );

    // Extract in parallel (3 at a time)
    const results = await extractDocuments(uploads);

    console.log('Extracted:', results);
  };

  return (
    <div>
      <input type="file" multiple onChange={(e) => e.target.files && handleBulkUpload(e.target.files)} />

      {documents.map((doc) => (
        <div key={doc.id}>
          <p>{doc.fileName}</p>
          {doc.isProcessing && <p>Processing... {doc.progress}%</p>}
          {doc.error && <p className="error">{doc.error}</p>}
          {doc.result && <p>✓ Extracted as {doc.result.documentType}</p>}
        </div>
      ))}
    </div>
  );
}
```

## Document Types & Schemas

### Lease (`LeaseData`)
```typescript
{
  type: 'lease',
  property: { address, unit, city, state, zipCode },
  parties: { tenant, landlord, propertyManager },
  terms: { rentAmount, securityDeposit, moveInDate, leaseStartDate, leaseEndDate },
  fees: { lateFee, parkingFee, petFee, ... },
  policies: { petPolicy, smokingPolicy, ... },
  utilities: { included, tenantResponsible },
  maintenance: { landlordResponsibilities, tenantResponsibilities }
}
```

### Inspection (`InspectionData`)
```typescript
{
  type: 'inspection',
  property: { address, propertyType },
  inspection: { date, inspector, inspectorLicense },
  summary: { overallCondition, majorIssues, minorIssues, passFailStatus },
  categories: [{ name, status, issues, estimatedRepairCost }],
  estimatedTotalRepairs: number
}
```

### Pre-Approval (`PreApprovalData`)
```typescript
{
  type: 'pre-approval',
  borrower: { name, email },
  lender: { name, loanOfficer, phone, email },
  approval: { amount, loanType, interestRate, term, expirationDate }
}
```

See `/types/documents.ts` for complete schemas.

## Best Practices

1. **Show Original Document**: Always provide a "View Original PDF" button
2. **Confidence Indicators**: Show confidence score, warn if < 70%
3. **Progressive Enhancement**: Show PDF first, then extracted data overlays
4. **Caching**: Cache extraction results in database
5. **Validation**: Add manual verification step for critical data
6. **Privacy**: Partially mask sensitive data (SSN, account numbers)

## Troubleshooting

### "Missing authorization header"
- Add authentication middleware to the API route
- Pass auth token in request headers

### "Failed to process document"
- Check OpenAI API key is set correctly
- Verify file URL is publicly accessible
- Check file format (should be PDF or image)

### Low confidence scores
- Document quality may be poor (low resolution, handwritten)
- Document type may not match training data
- Consider manual review for critical documents
